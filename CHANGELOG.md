# Changelog

What changed in each release of next5, in plain words for coaches. Newest first. The app shows the same notes under Settings → What’s new, and once after each update.

Changes that are merged but not released yet wait as notes in [`changes/`](changes/README.md). See "Releases" in the README for how a release is made.

## 0.4.0 (2026-11-12)

### New

- Plan practices on the new Practice tab: pick drills from your drill library (or start from about 20 starter drills), run stations with several coaches, drag drills into order, split balanced scrimmage teams, see one equipment list, share the plan with coaches and parents, see which drills won’t finish on time if it runs long, run it with a timer (with Undo for a wrong tap), and see how much time the season has spent on each kind of drill.

## 0.3.0 (2026-11-06)

### New

- Undo now takes back the last thing you did on game day, not just Next: a sub, an injury or rest, a late arrival, a re-plan or overtime.

### Improved

- When playing time can’t be equal, the warning says whether your locks, the position requirement or players being out is the likely reason.

## 0.2.1 (2026-11-05)

### Fixed

- The “new version is ready” message is no longer blurry: it now appears near the bottom of the screen.

## 0.2.0 (2026-11-05)

### New

- End a game early when time runs out: Edit → End game now. Only the segments played count, and Undo end of game brings it back.
- See the whole plan during a game: Edit → See full plan opens it at the lineup on the court now.
- Share the plan as text from the Grid view, for Messages, Notes or printing.
- See what changed in each update: a short note after updating, and Settings → What’s new.

### Improved

- Shared games show dates like “Sat, Nov 7”.
- Jersey numbers in the IN and OUT pairs, and a warning when two players have the same name.
- Positions show as G, F and C boxes on Game Day, the plan, the roster and the stats, and the bench shows what each player can play.
- Replace everything names any teams on this phone that aren’t in the backup and would be deleted.
- next5 says when the phone won’t keep the screen on, and how to set Auto-Lock to Never.

### Fixed

- Balance skill now judges players at the position they’re shown at, so it no longer warns about lineups it could have avoided.
- A damaged backup file or shared game is turned away with a message instead of causing problems later.
- Sending in someone else at the next sub now sticks when you re-plan later, and a re-plan never gets stuck on an earlier pick.
- The update message no longer appears during a game after moving between screens.

## 0.1.0 (2026-11-04)

### New

- Plan fair rotations that cover your positions, and run them on game day with one tap per sub.
- Change things during a game: sub out now, injuries, rests, late arrivals, re-planning and overtime.
- Lock players in or out, swap, and redo part of the plan before a game.
- Game and season stats, with CSV export.
- Share a game with an assistant by text link or AirDrop, at any point.
- Back up and restore your teams, light and dark appearance, archived teams, in-app help and a first-run intro.
